Fort Builder is a playful drag-and-drop game. Drag colorful blankets and pillows onto the fort area to construct your very own fort, then decorate it and play inside.

## Features

- **Blankets:** red, blue, purple, green, yellow and rainbow.
- **Pillows:** white, pink, star, heart and moon.
- **Extras:** fairy lights and more decorations.
- **No install:** plain HTML, CSS and JavaScript. Open `index.html` and play.

## Play

```sh
git clone https://github.com/Ethan-da-Tech-Wizard/fortz.git
cd fortz
open index.html
```

## Project layout

| Path | Purpose |
|---|---|
| `index.html` | Game page |
| `style.css` | Styling |
| `game.js` | Drag-and-drop game logic |
